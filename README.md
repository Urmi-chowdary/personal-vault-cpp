# personal-vault-cpp
A C++ Personal Vault Management System demonstrating all four OOP principles: Encapsulation, Abstraction, Inheritance, and Polymorphism. # PersonaVault – Smart App Permission & Privacy Analyzer

PersonaVault is a C++-based privacy analyzer that helps users identify unnecessary application permissions and potential privacy risks. It provides application registration, permission analysis, risk scoring, consent management, safer configuration recommendations, audit logging and website URL scanning. Built using C++14, HTML, CSS and JavaScript, the project demonstrates all four OOP principles: Encapsulation, Abstraction, Inheritance and Polymorphism through a modular and extensible architecture. Its goal is to promote privacy awareness and give users better control over their personal data.
