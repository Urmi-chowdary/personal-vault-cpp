Engineering documentation

Built with C++ OOP.

PersonaVault uses object-oriented design to separate application data, permission rules, scoring, consent management, storage and HTTP communication.

01 · Encapsulation

AppClient and DataAsset keep their internal fields private. Public getters and controlled methods such as addPermission() and removePermission() manage access to the data.

AppClient.h · DataAsset.h

02 · Abstraction

Rule is an abstract base class with pure virtual methods. PolicyEngine uses this common interface without needing to know each rule's internal implementation.

Rule.h · PolicyEngine.h

03 · Inheritance

PurposeRule, CombinationRule and SensitivityRule inherit from Rule. Each specialised class provides its own privacy evaluation behaviour.

Rule.h · Rule.cpp

04 · Polymorphism

PolicyEngine stores child rule objects through std::unique_ptr<Rule> and invokes evaluate(). The overridden implementation is selected at runtime.

PolicyEngine.cpp
